# 地址规划表

## 1. 地址规划原则

企业内网统一使用私有地址段 `192.168.0.0/16`。每个部门、团队、车间和服务器区域分配一个独立的 `/24` 子网，便于配置、扩展和故障排查。

核心交换机 CORE 为各 VLAN 提供默认网关，服务器采用固定 IP 地址，用户终端在仿真中采用静态地址配置，后续可扩展为 DHCP 自动分配。

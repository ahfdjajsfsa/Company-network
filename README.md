# 计算机网络实践项目

本仓库用于完成 2026 年《计算机网络实践》课程设计。根据新的命题文件，本项目需要完成两个内容：中小型企业网络工程设计与实现，以及一个基于 Socket 的通信软件设计与实现。当前 README 先对齐新的企业网络与 Socket 实践要求，其他既有资料后续再逐步调整。

## 任务一：中小型企业网络工程设计与实现

为某企业构建一个高性能、安全可靠的网络。企业场景包括三个建筑：行政楼、销售部、生产厂区，中心机房设在行政楼。

企业网络设计需要覆盖以下要求：

- 中心机房部署数据库服务器、重要业务服务器等内部资源，并禁止外部网络访问。
- 对外提供 WWW 服务，提供内外均可访问的 Email 服务。
- 内部用户可以访问外网，内外网络边界处可部署防火墙。
- 行政楼约 120 人，包含总经理办公室、人力资源部、财务部、技术部、工会、保卫和后勤等 6 个部门，不同部门处在不同楼层。
- 销售部门约 150 人，分成 5 个团队。
- 生产厂区分成 3 个车间，每个车间约 60 个用户。
- 不同部门、不同销售团队、不同生产车间之间不能二层通信，可通过三层路由和访问控制实现必要互通。
- 完成子网划分、IP 地址规划、VLAN 划分、路由设计、可选 ACL、WWW、MAIL、DNS 等网络服务规划与仿真测试。

报告需要包含以下内容：

1. 需求分析：描述企业网络需求，包括子网划分、VLAN、路由器 ACL（选做）、WWW、MAIL、DNS 等服务，以及服务支撑软件和主要原理。
2. 概要设计：绘制网络拓扑结构图，说明 VLAN 划分、子网规划、WWW 服务器、MAIL 服务器等主要功能实现过程。
3. 详细设计：整理核心交换机和路由器配置文件清单。
4. 调试分析：使用网络模拟软件或其他工具完成路由、交换、服务访问等通信测试。
5. 总结：总结设计过程、问题处理和改进方向。

# 校园网络设计项目

本文件夹下的所有内容用于完成一个校园网络设计与实现任务。项目目标是围绕典型校园场景（教学楼、实验楼、宿舍、图书馆、行政办公区、信息中心机房等）的网络基础设施需求，完成网络需求分析、概要设计、详细设计和调试分析，并形成可复现、可提交的设计文档与配置资料。

本项目将围绕以下内容展开：

- 校园网络需求分析（不同区域/人群的带宽、权限、可用性、安全要求）
- 子网与 IP 地址规划
- VLAN 划分与区域隔离（教学/办公/宿舍/访客/服务器区等）
- 路由与访问控制设计（可选：ACL、跨区访问策略、访客上网限制）
- WWW、FTP、MAIL、DNS 等服务规划（可选：校园门户、内网资源、教务/图书等系统的基础支撑）
- 核心交换机、接入交换机和路由器配置
- 网络仿真软件中的搭建步骤说明
- 通信测试与调试分析记录

目录中的 Markdown 文件用于记录设计思路、配置步骤和测试过程；`configs` 目录中的配置文件用于保存网络设备配置清单；`topology` 目录用于保存拓扑说明和地址规划；`simulation` 目录用于保存仿真实现说明和测试记录；`services` 目录用于保存服务器服务配置说明。

原要求:
中小型网络工程设计与实现
报告内容：
1、需求分析：详细描述对网络的需求。这些需求主要有子网划分、VLAN、路由器的ACL（选做）、所提供的服务（WWW、FTP、MAIL、DNS等等），每个服务采用的支撑软件，这些软件的主要原理。
2、概要设计：画出网络拓扑结构图，说明报告中主要功能的实现过程（VLAN 划分、子网规划、WWW服务器、FTP服务器、MAIL服务器等。
3、详细设计：核心交换机和路由器配置文件的清单。
4、调试分析：路由、交换之间采用网络模拟软件或其它进行通信测试。

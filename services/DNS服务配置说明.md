# DNS 服务配置说明

## 1. 服务作用

DNS 服务用于为校园网内部提供域名解析，使用户可以通过域名访问 WWW、FTP、MAIL 等服务器，而不需要直接记忆服务器 IP 地址。

## 2. 服务器地址

| 项目 | 配置 |
| --- | --- |
| 服务器名称 | DNS Server |
| 所属 VLAN | VLAN 50 SERVER |
| IP 地址 | 192.168.50.10 |
| 子网掩码 | 255.255.255.0 |
| 默认网关 | 192.168.50.1 |
| DNS 地址 | 192.168.50.10 |

## 3. Packet Tracer 配置步骤

1. 点击 DNS Server。
2. 进入 `Desktop -> IP Configuration`。
3. 配置 IP 地址、子网掩码、默认网关和 DNS 地址。
4. 进入 `Services -> DNS`。
5. 将 DNS 服务设置为 `On`。
6. 添加校园内部域名解析记录。

## 4. DNS 记录规划

| 域名 | 类型 | 解析地址 | 用途 |
| --- | --- | --- | --- |
| www.school.local | A | 192.168.50.20 | 校园门户网站 |
| ftp.school.local | A | 192.168.50.30 | 文件传输服务 |
| mail.school.local | A | 192.168.50.40 | 校园邮件服务 |

## 5. 终端配置要求

所有用户终端的 DNS 地址统一配置为：

```text
192.168.50.10
```

例如教学区 PC：

| 项目 | 配置 |
| --- | --- |
| IP 地址 | 192.168.10.10 |
| 默认网关 | 192.168.10.1 |
| DNS | 192.168.50.10 |

## 6. 测试方法

在 PC 上进行以下测试：

1. `ping 192.168.50.10`，测试能否访问 DNS 服务器。
2. 在浏览器访问 `http://www.school.local`，测试 DNS 是否能解析 WWW 服务器。
3. 使用 FTP 客户端访问 `ftp.school.local`。
4. 使用邮件客户端配置 `mail.school.local`。

如果通过域名无法访问，但通过 IP 可以访问，说明 DNS 服务或 DNS 记录配置有误。
